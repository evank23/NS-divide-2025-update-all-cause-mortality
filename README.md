# NS-divide-2025-update-all-cause-mortality

Stata code (in respective fodler) for all analyses (and more) reported in the 2026 analysing all-cause mortality in the North vs the South of England
The wrapper calls all other files. 
A Stata project file is also included
Comments are added in all files as to what they analyse and report.

R scripts (in respective folder) for the counterfactual analyses of the size of the error in the Northern denominator(s) that would explain away the observed differences in mortality.
